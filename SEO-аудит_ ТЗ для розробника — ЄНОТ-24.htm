SEO-аудит: Технічне завдання для розробника

Сайт: enot-24.com.ua Конкурент: ceh.ua Травень 2026

1. Пояснення: мета-теги vs мікророзмітка

Мета-теги (title, description, og-теги)

Це невидимий для відвідувачів код у <head> кожної сторінки. Саме його Google читає і показує у результатах пошуку. Якщо title неправильний — Google не розуміє, по якому запиту ранжувати сторінку. Якщо description порожній — Google або придумує його сам (часто погано), або бере перший абзац тексту.

Мікророзмітка Schema.org

Це окремий блок коду (зазвичай JSON-LD у тезі <script>), який говорить Google: «ця сторінка — послуга», «ось ціна», «ось адреса організації». Завдяки мікророзмітці у результатах пошуку з'являються зірочки, ціна, адреса прямо у видачі — так звані rich snippets.

⚠ У ЄНОТ-24 мікророзмітки немає взагалі. На сторінках послуг також відсутні майже всі мета-теги. Саме через це конкурент ЦЕХ вище у видачі — не тому що кращий, а тому що технічно правильніше оформлений.

3. Завдання для розробника

ℹ Всі правки нижче стосуються шаблону сторінок послуг. Оскільки таких сторінок сотні — розробнику потрібно змінити шаблон один раз, і всі сторінки закриються автоматично.
Критично

Завдання 1 — Виправити формат <title>

Зараз (погано)
Балетки - Послуга хімчистки - Екочистка одягу та домашнього текстилю
Потрібно (добре)
Хімчистка балеток у Києві — ціна, кур'єр | ЄНОТ-24
Шаблон
{Назва послуги} у Києві — ціна, кур'єр | ЄНОТ-24
⚠ Довжина title — не більше 60 символів. Якщо назва послуги довга — скорочувати.
Критично

Завдання 2 — Додати <meta name="description">

Зараз цей тег відсутній на всіх сторінках послуг. Потрібно додати шаблон:

Шаблон
{Назва послуги} у Києві від ЄНОТ-24. Професійна чистка, безпечна хімія, кур'єрська доставка. Актуальні ціни.

Приклад готового тегу:

<meta name="description"
      content="Хімчистка балеток у Києві від ЄНОТ-24. Професійна чистка, безпечна хімія, кур'єрська доставка. Актуальні ціни.">
⚠ Оптимальна довжина: 130–160 символів. Більше 160 — Google обрізає в сніпеті.
Критично

Завдання 3 — Додати canonical URL

Canonical вказує Google яка URL є основною — захист від дублювання контенту.

<link rel="canonical" href="https://enot-24.com.ua{поточний URL сторінки}">
Важливо

Завдання 4 — Додати повний комплект og-тегів

Open Graph теги потрібні для коректного відображення при поширенні в соцмережах і для сигналів Google.

<meta property="og:title"       content="{той самий title}">
<meta property="og:description"  content="{той самий description}">
<meta property="og:url"         content="https://enot-24.com.ua{URL}">
<meta property="og:locale"      content="uk_UA">
<meta property="og:site_name"   content="ЄНОТ-24">
<meta property="og:type"        content="website">
<meta property="og:image"       content="https://enot-24.com.ua/storage/src/logo/enot-white-bg.png">
Важливо

Завдання 5 — Додати twitter:card теги

<meta name="twitter:card"        content="summary_large_image">
<meta name="twitter:title"       content="{той самий title}">
<meta name="twitter:description"  content="{той самий description}">
<meta name="twitter:image"       content="https://enot-24.com.ua/storage/src/logo/enot-white-bg.png">
Важливо

Завдання 6 — Виправити meta robots

Зараз
index, follow
Потрібно
index, follow, max-image-preview:large, max-snippet:-1, max-video-preview:-1

max-snippet:-1 дозволяє Google показувати більший фрагмент тексту у видачі — це підвищує CTR.

Важливо

Завдання 7 — Додати мікророзмітку Schema.org

Мікророзмітка дозволяє Google показувати розширені сніпети у видачі (ціна, адреса, зірочки відгуків). Додати три типи:

7а. CleaningService — один раз на головній сторінці

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "CleaningService",
  "name": "ЄНОТ-24",
  "url": "https://enot-24.com.ua",
  "telephone": "+380678872233",
  "address": {
    "@type": "PostalAddress",
    "addressLocality": "Київ",
    "addressCountry": "UA"
  },
  "openingHours": "Mo-Su 09:00-21:00",
  "priceRange": "$$"
}
</script>

7б. Service + Offer — на кожній сторінці послуги (шаблон)

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "Service",
  "name": "{Назва послуги}",
  "provider": { "@type": "LocalBusiness", "name": "ЄНОТ-24" },
  "areaServed": "Київ",
  "offers": {
    "@type": "Offer",
    "price": "{ціна послуги}",
    "priceCurrency": "UAH"
  }
}
</script>

7в. BreadcrumbList — хлібні крихти на кожній сторінці

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "Головна", "item": "https://enot-24.com.ua" },
    { "@type": "ListItem", "position": 2, "name": "{Категорія}", "item": "{URL категорії}" },
    { "@type": "ListItem", "position": 3, "name": "{Назва послуги}", "item": "{URL послуги}" }
  ]
}
</script>

5. Як перевірити результат

✓ Всі інструменти нижче — безкоштовні.
  • Google Search Console → Покриття → перевірити що сторінки індексуються після правок
  • Google Rich Results Test (search.google.com/test/rich-results) → вставити URL послуги → перевірити мікророзмітку
  • Serpstat → Аналіз домену → enot-24.com.ua → порівняти видимість до і після (є 7-денний безкоштовний тест)
  • Ввести у Google site:enot-24.com.ua і подивитись як виглядають сніпети — чи підтягнулись description
